# pack-starter

A minimal Scaffoldix pack template to bootstrap new packs quickly.

## What's included

```
starters/pack-starter/
  archetype.yaml                    # Pack manifest with one 'default' archetype
  templates/
    default/
      __EntityName__.ts             # Entity interface + service (Handlebars template)
      __EntityName__.test.ts        # Vitest unit tests for the service
      README.md                     # Generated README template
  helpers/                          # (empty) Drop .js Handlebars helper files here
  partials/                         # (empty) Drop .hbs Handlebars partial files here
  patches/                          # (empty) Drop .hbs patch content templates here
```

## Using this starter

### Option A — copy and customise

```bash
cp -r starters/pack-starter my-pack
cd my-pack
# Edit archetype.yaml: set pack.name, add your own inputs and templates
```

### Option B — use scaffoldix generate (if you have a pack-starter pack installed)

```bash
scaffoldix generate pack-starter:default --target my-new-pack
```

## Customising the archetype

### 1. Rename the pack

Edit `archetype.yaml`:
```yaml
pack:
  name: "my-awesome-pack"
  version: "0.1.0"
```

### 2. Add inputs

```yaml
inputs:
  - name: entityName
    prompt: "Entity name:"
    type: string
    required: true
    transforms:
      - PascalCase
      - camelCase
      - kebab-case
```

Available transform names: `PascalCase`, `camelCase`, `kebab-case`, `snake_case`,
`UPPER_SNAKE`, `lower`, `upper`, `title`, `dot.case`, `path/case`.

Each transform produces a new variable: `entityNamePascalCase`, `entityNameCamelCase`,
`entityNameKebabCase`, etc.

### 3. Add Handlebars helpers

Drop `.js` files into `helpers/`. Each exported function becomes a Handlebars helper
named after its export:

```js
// helpers/plural.js
export function plural(str) {
  return str.endsWith("s") ? str : str + "s";
}
// Usage in template: {{plural entityName}}
```

### 4. Add partials

Drop `.hbs` files into `partials/`. The filename (without extension) is the partial name:

```handlebars
{{!-- partials/header.hbs --}}
/**
 * Generated by Scaffoldix
 * @generated
 */
```

```handlebars
{{!-- Usage in template --}}
{{> header}}
```

### 5. Add patches

Patches modify existing files after templates are written. Uncomment the `patches`
section in `archetype.yaml` and adjust the marker, file path, and content template.

## Publishing your pack

```bash
# Make sure scaffoldix-pack keyword is present in package.json (auto-added by publish command)
scaffoldix pack publish
```

Users can then install your pack:
```bash
scaffoldix pack add npm:<your-pack-name>
```
